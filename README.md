# Aeronaut — тёмная вишня Vinery

Схематика размером 16 × 26 × 67 в формате Minecraft Structure NBT.

В файле `aeronaut_16x26x67_hull_vinery_dark_cherry_aeronauticswhite_envelope.nbt` все 1 544 блока тёмного дуба заменены на тёмную вишню из [Let's Do] Vinery:

- 1 005 досок — `vinery:dark_cherry_planks`;
- 343 ступени — `vinery:dark_cherry_stairs`;
- 86 плит — `vinery:dark_cherry_slab`;
- 110 блоков забора — `vinery:dark_cherry_fence`.

Координаты, свойства и ориентация блоков сохранены. Белая оболочка `aeronautics:white_envelope` сохранена. Для загрузки нужны соответствующие моды Vinery и Aeronautics.

NBT проверен повторным чтением и побайтовым сравнением после замен ID. Проверка в игре не проводилась.
